# 💛❤️ Karnataka Heart – Java

A mathematical heart artwork inspired by
the Karnataka flag, created using Java.

## Technologies Used
- Java
- Java Swing
- Graphics2D
- Mathematical equations

## How to Run

1. Install JDK.
2. Open the project folder.
3. Run:

javac JaiKarnataka.java
java JaiKarnataka
